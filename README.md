# DIDGORI — საცდელი ვერსია

[**ჩამოტვირთე Windows-ის საინსტალაციო — 2026.10.6.18**](https://github.com/vakojin/didgori-updates/releases/download/v2026.10.6.18/DIDGORI-Setup-2026.10.6.18.exe)

საინსტალაციო დაახლოებით 1.47 გბ-ია. თამაში განკუთვნილია 64-ბიტიანი Windows-ისთვის; Unreal Engine-ის ცალკე დაყენება საჭირო არ არის.

ამ გამოშვებაში არის სამი კუნძულის რუკა და რვა სახელმწიფო: რომი, საქართველო, საბერძნეთი, ბაბილონი, სპარსეთი, იაპონია, ეგვიპტე და ინდოეთი. ახალი პარტია იწყება ერთი მთავარი შენობითა და სამი მუშით; შემდეგ შეგიძლია შენობების აშენება, მეომრების გაწვრთნა და პარტიის შენახვა.

## დაყენება და გახსნა

1. ჩამოტვირთე საინსტალაციო, გაუშვი და მიჰყევი ინსტალაციის ნაბიჯებს.
2. გახსენი DIDGORI ინსტალაციისას შექმნილი აიქონიდან.
3. თუ აიქონი ვერ იპოვე, დააჭირე **Win + R**, ჩასვი `"%LOCALAPPDATA%\Programs\DIDGORI\Launcher\v1\DIDGORI-Launcher.exe"` და დააჭირე Enter.

ძველი `2026.10.5.14` საინსტალაციოს მომხმარებლებმა ეს ახალი საინსტალაციო ერთხელ უნდა დააყენონ, რათა თამაშიდან განახლება მიიღონ.

## შემდგომი განახლებები

თამაშის მენიუში აირჩიე **განახლება → შემოწმება**. როცა ახალი ვერსია ამ გვერდზე გამოქვეყნდება, თამაში შემოგთავაზებს მის ჩამოტვირთვასა და დაყენებას.

მიმდინარე პარტიისას გამოიყენე **შენახვა და განახლება**; დაწყებული კამპანიის გარეშე — **განახლება და ხელახლა ჩართვა**. შემდეგ აირჩიე **კამპანიის გაგრძელება**. თუ გამშვები Windows-ის გადატვირთვას მოითხოვს, ჯერ გადატვირთე Windows.

შენახვები ინსტალაციის საქაღალდისგან განცალკევებულია. განახლების ფაილის ხელმოწერა და საინსტალაციოს საკონტროლო ჯამი მოწმდება. თამაშიდან განახლება მიიღებს აქ გამოქვეყნებულ ახალ ვერსიებს; დაუქვეყნებელი სამუშაო ცვლილებები მოთამაშეებთან არ გადავა.
