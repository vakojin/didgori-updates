# DIDGORI — საცდელი ვერსია

[**უახლესი ვერსიის ჩამოტვირთვის გვერდი**](https://github.com/vakojin/didgori-updates/releases/latest) · [**Windows-ის საინსტალაციო — 2026.10.7.19**](https://github.com/vakojin/didgori-updates/releases/download/v2026.10.7.19/DIDGORI-Setup-2026.10.7.19.exe)

თამაში განკუთვნილია 64-ბიტიანი Windows-ისთვის. სათამაშოდ Unreal Engine-ის ცალკე დაყენება საჭირო არ არის.

2026.10.7.19 ვერსიაში მენიუს არჩეულ წითელ ღილაკებზე წარწერები თეთრია და თამაშს ახალი ხატულა აქვს. შენარჩუნებულია სამი კუნძულის რუკა, ლურჯი ზღვა, არსებული მოდელები და რვა სახელმწიფო: რომი, საქართველო, საბერძნეთი, ბაბილონი, სპარსეთი, იაპონია, ეგვიპტე და ინდოეთი.

## დაყენება და გახსნა

ჩამოტვირთე საინსტალაციო, გაუშვი და მიჰყევი ნაბიჯებს. შემდეგ გახსენი **Windows-ის Start მენიუ → DIDGORI**.

თუ მენიუში ვერ იპოვე, დააჭირე **Win + R**, ჩასვი `"%LOCALAPPDATA%\Programs\DIDGORI\Launcher\v1\DIDGORI-Launcher.exe"` და დააჭირე Enter.

ძველი `2026.10.5.14` ვერსიის მომხმარებლებმა ახალი საინსტალაციო ერთხელ უნდა დააყენონ, რათა შემდეგ თამაშიდან მიიღონ განახლებები.

## თამაშიდან განახლება

გახსენი **განახლება → შემოწმება**. აქ გამოქვეყნებული ახალი ვერსია თამაშშიც გამოჩნდება; დაუქვეყნებელი სამუშაო ცვლილებები მოთამაშეებთან არ გადავა.

მიმდინარე პარტიისას აირჩიე **შენახვა და განახლება**; დაწყებული კამპანიის გარეშე — **განახლება და ხელახლა ჩართვა**. ჩამოტვირთვისა და დაყენების შემდეგ თამაში ხელახლა ჩაირთვება. შენახულ პარტიაში დასაბრუნებლად აირჩიე **კამპანიის გაგრძელება**. თუ გამშვები Windows-ის გადატვირთვას მოითხოვს, ჯერ გადატვირთე Windows.

შენახვები ინსტალაციის საქაღალდისგან განცალკევებულია. განახლების ხელმოწერა და საინსტალაციოს საკონტროლო ჯამი მოწმდება.

საინსტალაციო თამაშისა და განახლებისთვისაა. რომის ან სხვა ქვეყნების დასამუშავებლად საჭიროა ცალკე სამუშაო Unreal პროექტი; საინსტალაციოში ის არ შედის.
