# DIDGORI Preview

**გამოშვება ჯერ არ არის ხელმისაწვდომი.** ეს გვერდი მზადდება Windows-ის საინსტალაციოსა და განახლებების გასავრცელებლად. ჩამოტვირთვა გამოჩნდება [Releases-ის გვერდზე](https://github.com/vakojin/didgori-updates/releases), როცა გამოშვება შემოწმდება და გამოქვეყნდება.

პირველი ახალი საინსტალაციოს გამოქვეყნების შემდეგ:

1. ჩამოტვირთე `DIDGORI-Setup-*.exe`, გაუშვი და მიჰყევი ინსტალაციის ნაბიჯებს.
2. გახსენი DIDGORI შექმნილი მალსახმობიდან.
3. თამაშის მენიუში აირჩიე **განახლება → შემოწმება**. ახალი ვერსიის არსებობისას გამოიყენე **შენახვა და განახლება**; დაწყებული კამპანიის გარეშე — **განახლება და ხელახლა ჩართვა**.
4. ხელახლა გაშვების შემდეგ აირჩიე **კამპანიის გაგრძელება**. თუ გამშვები Windows-ის გადატვირთვას მოითხოვს, ჯერ გადატვირთე Windows.

თამაშიდან განახლება ხელმისაწვდომი იქნება პირველი ახალი საინსტალაციოს დაყენებისა და განახლების სერვისის ამუშავების შემდეგ. ძველი საინსტალაციო ამ შესაძლებლობას ჯერ არ შეიცავს.

მიმდინარე კოდში შენახვები ინსტალაციის საქაღალდისგან განცალკევებულია და განახლება კამპანიის შენახვის დასრულებას ელოდება. რეალური ინსტალაციისა და განახლებისას ამ ქცევის შემოწმება ჯერ არ დასრულებულა. წარმადობის გაუმჯობესება ამ ეტაპზე დადასტურებული არ არის.

ხარვეზის აღწერა შეგიძლია დაამატო [Issues-ში](https://github.com/vakojin/didgori-updates/issues).
